# GAP-анализ и проектирование TO-BE процесса логистической компании

## 📋 Описание проекта

Проект посвящён анализу текущего бизнес-процесса приёма и обработки заявок в логистической компании (AS-IS), выявлению разрывов (GAP) с целевым состоянием (TO-BE) и разработке рекомендаций по оптимизации процесса.

## 🎯 Цель

Определить узкие места существующего процесса и предложить конкретные решения для их устранения с приоритизацией по эффекту и сложности внедрения.

## Матрица GAP-анализа

| Параметр | AS-IS | TO-BE (цель) | GAP (разрыв) | Приоритет |
|---|---|---|---|---|
| Канал приёма заявок | Телефон, email, WhatsApp, Telegram, лично | Единый портал + API | Нет единого канала, заявки теряются/дублируются | Высокий |
| Время подтверждения заявки | 3,5 рабочих дня | ≤ 4 часов | Отставание 3+ дня | Высокий |
| Расчёт стоимости | В уме / Excel, «по опыту» | Автоматический калькулятор | Нет прозрачности и единой методики | Средний |
| Согласование договора | 2,8 рабочих дня, бумажный документооборот | Электронная подпись, согласование почти моментально | Бумажный оборот тормозит процесс | Высокий |
| Уведомления клиенту | Нет — клиент сам звонит и уточняет статус | Push / SMS / Email уведомления автоматически | Отсутствие проактивной коммуникации | Высокий |
| Отслеживание груза | Звонок диспетчеру → звонок водителю | GPS-трекинг в реальном времени | Нет видимости местоположения груза | Средний |
| Выставление счёта | 4,2 рабочих дня, вручную | Автоматически в момент доставки | Ручной труд, задержка выставления | Средний |
| Аналитика и отчётность | Excel, «на глаз» | Dashboard с KPI в реальном времени | Нет достоверных агрегированных данных | Низкий |

## Предложения по улучшению

| № | Улучшение | Затрагиваемые шаги | Эффект | Сложность |
|---|---|---|---|---|
| 1 | Внедрить единый портал для приёма заявок (с API) | Шаги 1–3 | Сокращение времени приёма заявки до ~30 мин | Высокая |
| 2 | Автоматизировать расчёт стоимости (калькулятор) | Шаг 5 | Прозрачность для клиента, скорость расчёта | Средняя |
| 3 | Внедрить электронную подпись для договоров | Шаги 7–8 | Согласование: с 2,8 дня до минут | Средняя |
| 4 | Реализовать автоматические уведомления клиенту | Шаг 11 | Снижение входящих звонков на ~80% | Низкая |
| 5 | Интегрировать GPS-отслеживание груза | Шаги 10–12 | Полная прозрачность статуса для клиента | Средняя |
| 6 | Автоматизировать выставление счетов | Шаг 13 | С 4,2 дня до момента доставки | Низкая |

## Рекомендации по приоритизации

Начинать стоит с улучшений с высоким эффектом и низкой/средней сложностью — это **«быстрые победы»**:

1. ✅ **Автоматические уведомления клиенту** — низкая сложность, высокий эффект
2. ✅ **Автоматизация выставления счетов** — низкая сложность, ускоряет оборот средств
3. ✅ **Электронная подпись** — средняя сложность, кардинально ускоряет согласование
